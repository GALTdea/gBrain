# Data Model, Storage & Security Architecture

## 1. Core Architectural Rule: Subcollection Isolation
To guarantee strict privacy between Gustavo and Gianna—and to bypass Firestore's composite vector index limitations—all user notes live inside an isolated subcollection per user:

```text
users/{userId}/notes/{noteId}
```

* **Why Subcollections Matter for Vector Search:** Firestore's `findNearest` vector queries require composite indexes if pre-filtered with `.where("userId", "==", uid)`. By partitioning notes under `users/{userId}/notes`, every vector query runs directly against a single user's collection reference without needing composite pre-filters, and cross-user leakage is structurally impossible.

## 2. Firestore `Note` Document Schema

Defined in [`src/types/note.ts`](file:///Users/gustavo/dev/projects/gBrain/src/types/note.ts) and persisted at `users/{userId}/notes/{noteId}`:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Yes | Document ID (e.g., `note_<ts>_<rand>`, `capture_<ts>_<rand>`, `voice_<ts>_<rand>`, `keep_note_001`) |
| `title` | `string` | Yes | Note title (user-entered, AI-generated for voice memos, or derived from first line/hostname) |
| `content` | `JSONContent` | Yes | Raw TipTap ProseMirror JSON tree (`{ type: "doc", content: [...] }`) used for rich editing |
| `plain_text` | `string` | Yes | Stripped plain-text representation used for vector embeddings, keyword search, and card previews |
| `tags` | `string[]` | No | Normalized lowercase tag strings without `#` prefix (e.g., `["voice-memo", "capture"]`) |
| `embedding` | `VectorValue \| number[]` | No | 768-dimensional float vector generated by `text-embedding-004` / `gemini-embedding-001`. Stored via `FieldValue.vector(...)` on the server with standard `number[]` fallback |
| `hasEmbedding` | `boolean` | No | Metadata flag set by `/api/embed` and `/api/seed` indicating vector index readiness |
| `embeddingUpdatedAt` | `number` | No | Epoch ms timestamp of last embedding computation |
| `audioUrl` | `string` | No | Firebase Storage HTTPS download URL for inline HTML5 `<audio>` playback |
| `audioStorageUri` | `string` | No | `gs://<bucket>/users/{userId}/audio/<file>` URI for Vertex AI multimodal access |
| `userId` | `string` | Yes | Owner's Firebase Auth UID |
| `createdAt` | `number` | Yes | Creation timestamp in epoch milliseconds |
| `updatedAt` | `number` | Yes | Last modification timestamp in epoch milliseconds |

### Content Separation Invariant (Rule 3)
Every note mutation must keep `content` (TipTap JSON) and `plain_text` synchronized:
* When editing in [`TipTapEditor.tsx`](file:///Users/gustavo/dev/projects/gBrain/src/components/editor/TipTapEditor.tsx), `editor.getJSON()` populates `content` and `editor.getText()` populates `plain_text`.
* When [`saveNote()`](file:///Users/gustavo/dev/projects/gBrain/src/lib/notes/notes-service.ts#L121-L220) detects that `plain_text` changed compared to `previousPlainText` (or if `embedding` is missing), it asynchronously triggers `POST /api/embed` to compute and merge the updated 768-dimensional vector.

## 3. Client-Side Storage Layers

### A. IndexedDB (`gbrain_offline_store`)
Managed by [`src/lib/voice/voice-draft-store.ts`](file:///Users/gustavo/dev/projects/gBrain/src/lib/voice/voice-draft-store.ts) and [`public/sw.js`](file:///Users/gustavo/dev/projects/gBrain/public/sw.js) (DB Version `1`):

1. **`shared_media` Object Store (`keyPath: "id"`):**
   * Used by the Service Worker when intercepting `POST /capture-share-target` requests (such as shared audio files from Pixel Recorder).
   * Stores [`SharedMediaPayload`](file:///Users/gustavo/dev/projects/gBrain/src/lib/voice/voice-draft-store.ts#L8-L18) (`id`, `title`, `text`, `url`, `hasAudio`, `audioBlob`, `audioName`, `audioType`, `timestamp`).
   * Consumed and deleted by [`/capture/page.tsx`](file:///Users/gustavo/dev/projects/gBrain/src/app/capture/page.tsx#L113-L184) once transcribed and saved.
2. **`voice_drafts` Object Store (`keyPath: "id"`):**
   * Used by [`VoiceRecorder.tsx`](file:///Users/gustavo/dev/projects/gBrain/src/components/voice/VoiceRecorder.tsx) during active microphone recording.
   * Stores [`VoiceDraft`](file:///Users/gustavo/dev/projects/gBrain/src/lib/voice/voice-draft-store.ts#L20-L35) (`id`, `userId`, `chunks: Blob[]`, `mimeType`, `extension`, `startedAt`, `durationSeconds`, `status`, `targetNoteId`, `sharedContext`).
   * Appends a new `Blob` chunk every `1000ms` (`appendDraftChunk`) so long voice thoughts are crash-safe. Deleted automatically once `/api/voice` and `saveNote` succeed.

### B. `localStorage` Keys
* `gbrain_demo_notes_<userId>`: Used by [`notes-service.ts`](file:///Users/gustavo/dev/projects/gBrain/src/lib/notes/notes-service.ts#L13-L36) as an offline safety fallback if Firebase is unconfigured or unreachable.

## 4. Security Rules

### Firestore Security Rules ([`firestore.rules`](file:///Users/gustavo/dev/projects/gBrain/firestore.rules))
* Default denies all reads and writes across the database (`match /{document=**} { allow read, write: if false; }`).
* Explicitly permits read/write on `/users/{userId}` and `/users/{userId}/notes/{noteId}` **only** when `request.auth != null && request.auth.uid == userId`.

### Firebase Storage Security Rules ([`storage.rules`](file:///Users/gustavo/dev/projects/gBrain/storage.rules))
* Default denies all paths (`match /{allPaths=**} { allow read, write: if false; }`).
* Scopes audio uploads to `/users/{userId}/audio/{fileName}`:
  * **Read:** `request.auth != null && request.auth.uid == userId`
  * **Write:** `request.auth != null && request.auth.uid == userId && request.resource.size < 25 * 1024 * 1024 && request.resource.contentType.matches('audio/.*')`
